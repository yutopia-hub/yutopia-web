---
description: 너무 커진 파일을 역할별로 분리
---

다음 파일이 너무 커지거나 여러 역할을 섞어서 하고 있습니다: $ARGUMENTS

요구사항:

1. 이 파일이 현재 담당하는 역할을 목록으로 먼저 정리해줘 (리팩토링 전에 보여줘).
2. 역할 단위로 쪼갤 수 있으면 분리안을 제시해줘. 이 프로젝트 구조(`src/pages`, `src/components`, `src/api`, `src/store`, `src/utils`) 중 어디로 가야 하는지 각각 명시.
3. 기능/동작은 절대 바꾸지 말고 순수하게 이동/분리만 한다 (리네이밍 포함).
4. 분리 후 import 경로를 전부 맞게 수정하고, 해당 폴더의 AGENT.md 규칙(있다면)을 따른다.
5. 끝나면 `npm run build`로 빌드 에러 없는지 확인해줘.

과하게 쪼개지 말 것: 역할이 명확히 2개 이상으로 나뉠 때만 분리하고, 추측성 추상화는 추가하지 않는다.
