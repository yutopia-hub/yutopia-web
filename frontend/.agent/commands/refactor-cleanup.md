다음 대상을 정리해줘 (파일/폴더/diff): $ARGUMENTS

요구사항:

1. 기능 변경 없이 가독성/중복 제거만 한다.
2. 중복 로직이 3곳 이상 반복될 때만 헬퍼로 뽑는다. 1~2곳이면 그대로 둔다.
3. 쓰지 않는 import, 죽은 코드, 불필요한 주석을 제거한다.
4. 이 프로젝트 컨벤션(바닐라 JS, 템플릿 리터럴 기반 렌더링, `utils/dom.js` 헬퍼 사용)을 벗어나지 않는다. 프레임워크나 새 라이브러리를 끌어오지 않는다.
5. 변경 후 `npm run build`로 깨진 게 없는지 확인하고, 바뀐 부분을 간단히 요약해줘.
