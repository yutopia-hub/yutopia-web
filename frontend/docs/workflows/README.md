# Workflows

기능 영역(폴더)별로 "뭔가 새로 추가할 때 어떤 순서로 하면 되는지"를 정리한 문서.
각 파일은 해당 폴더에서 작업을 시작하기 전에 한 번 읽는 용도.

- [api-workflow.md](./api-workflow.md) — 새 API 연동/리소스 추가
- [pages-workflow.md](./pages-workflow.md) — 새 페이지/라우트 추가
- [components-workflow.md](./components-workflow.md) — 공용 컴포넌트 추가/수정
- [state-workflow.md](./state-workflow.md) — 전역 상태 추가
